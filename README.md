# DwaBot – Obstacle Avoiding Robot

## Project Overview

DwaBot is an obstacle-avoiding robot designed to detect obstacles in its path and automatically change its direction to avoid collisions.

## Objective

- Build an autonomous obstacle-avoiding robot.
- Detect obstacles using sensors.
- Control the movement of the robot based on sensor readings.
- Implement automatic direction control.

## Components Used

- Arduino UNO
- Ultrasonic Sensor
- DC Motors
- Motor Driver
- Robot Chassis
- Wheels
- Battery

## Working

The ultrasonic sensor continuously detects obstacles in front of the robot. When an obstacle is detected within a specified distance, the Arduino processes the sensor data and controls the motors to change the robot's direction and avoid the obstacle.

## Technologies Used

- Arduino
- Embedded C/C++
- Ultrasonic Sensing
- Motor Control

## Project Outcome

A functional autonomous robot capable of detecting obstacles and navigating around them without direct human control.
